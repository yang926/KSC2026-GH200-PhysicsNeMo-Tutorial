# 원본 시각 자료 보존

이 폴더에는 OpenHackathons 원본 저장소의 이미지와 동영상 자산을 보존합니다.

- `upstream/introduction`: PhysicsNeMo와 PINN 소개 자료
- `upstream/diffusion_1d`: 1D diffusion 시각 자료
- `upstream/navier_stokes`: Navier–Stokes 및 ParaView 시각 자료
- `upstream/fluid`: Fluid–Structure Interaction 시각 자료
- `upstream/challenge_plots`: 원본 challenge plot
- `upstream/misc`: 원본 Git/GitHub 안내 이미지
- `upstream/references`: 원본 PhysicsNeMo industrial use-cases PDF와 contributor guide
